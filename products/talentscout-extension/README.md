## ⚡ Hướng Dẫn Cài Đặt (Chỉ 10 Giây):

1. **Giải nén** file `talentscout-linkedin-extension-pro.zip` vào một thư mục trên máy tính.
2. Mở trình duyệt **Google Chrome**, **Cốc Cốc**, **Brave** hoặc **Microsoft Edge**.
3. Truy cập đường dẫn: `chrome://extensions/` (hoặc `edge://extensions/`).
4. Bật công tắc **"Chế độ dành cho nhà phát triển" (Developer mode)** ở góc trên bên phải.
5. Bấm nút **"Tải tiện ích đã giải nén" (Load unpacked)** và chọn thư mục `talentscout-extension` vừa giải nén.
6. Ghim icon 🐸 **TalentScout AI** lên thanh tiện ích trình duyệt để sử dụng ngay!
