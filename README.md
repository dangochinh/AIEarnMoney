## 💻 Hướng Dẫn Chạy & Thử Nghiệm

### Cách 1: Chạy bằng máy chủ Python (Khuyên dùng)
```bash
cd /Users/happypc/AIEarnMoney
python3 server/app.py
```
Mở trình duyệt truy cập: **`http://localhost:8080`**

### Cách 2: Mở trực tiếp bằng bất kỳ trình duyệt nào
Website được thiết kế hoàn toàn theo tiêu chuẩn web tĩnh hiện đại. Bạn chỉ cần click đúp vào file `index.html` là trang web hoạt động đầy đủ 100%!

## 🔐 Bảng Điều Khiển Bí Mật Dành Cho Anh Chủ (Secret Admin Panel)

- **Cách 1**: Bấm liên tiếp **5 lần** vào linh vật Ếch Pepe trên trang chủ.
- **Cách 2**: Bấm tổ hợp phím **`Cmd + Shift + A`** (trên Mac) hoặc **`Ctrl + Shift + A`** (trên Windows).
- **Tính năng**:
  - Cập nhật số tiền thật kiếm được (Earned).
  - Cập nhật tiền chi mặt (Cash spent) và chi phí AI quy đổi.
  - Thay đổi số tài khoản ngân hàng / MoMo nhận tiền.
  - Thêm dòng nhật ký mới theo thời gian thực mà không cần sửa code bằng tay!

## ☁️ Hướng Dẫn Triển Khai Miễn Phí (Deploy to Cloudflare / GitHub)

1. **Cloudflare Pages (Khuyên dùng - 0đ trọn đời)**:
   - Đăng nhập [Cloudflare Dashboard](https://dash.cloudflare.com/) -> `Pages` -> `Create a project`.
   - Kết nối GitHub repo `AIEarnMoney` hoặc kéo thả trực tiếp thư mục này lên.
   - Trang web sẽ online ngay với tên miền dạng `pepe-nuoi-than.pages.dev` siêu tốc!

2. **GitHub Pages**:
   - Đẩy code lên GitHub repository.
   - Vào `Settings` -> `Pages` -> chọn branch `main` / root folder -> Save.
